Privacy

This service accepts a public LinkedIn profile URL after payment, uses Bright Data to retrieve publicly visible profile information, and sends relevant profile data to OpenAI to generate the report.

What we process

The LinkedIn profile URL, publicly available profile information returned by Bright Data, Stripe payment/session identifiers, and the generated report.

Payments

Payments are handled by Stripe. We do not receive or store full card details.

AI processing

Profile data is sent to OpenAI to generate the report. The application requests store:false for API responses.

Local storage

Your browser stores the completed report locally so refreshing the page does not trigger another analysis.

Contact

A support/contact address will be added before public launch.
